Modern Web Core

The essential patterns for semantic, accessible, and performant web applications.

1. Quick Ref: Semantics & Media

Text & Structure

<p> Block

The standard for paragraphs. Never use <br> to create space use CSS margins.

<strong> Semantic

Use for important text. <b> is strictly for visual bolding without added meaning.

<em> Semantic

Use for emphasis. <i> is for visual italics (e.g., technical terms).

Navigation & Media

<a href="..."> Anchor

The href attribute is mandatory for a valid link. Always use descriptive text, not "click here".

<img> Self-Closing

Requires an alt attribute for accessibility. This is non-negotiable.

<img src="hero.jpg" alt="A sunset over mountains">

<source> Media

Used inside <video> or <audio> to provide multiple formats (WebM/MP4) for compatibility.

2. Accessibility (a11y)

Accessibility is not an "extra"—it is a requirement for a professional product.

The "Big Three" Rules

Alt Text Visuals

Every image needs an alt. If the image is purely decorative (like a background swirl), use an empty alt: alt="". This tells screen readers to skip it.

ARIA Labels Context

If a button only has an icon (no text), use aria-label="Close Menu" so a screen reader can describe the button's action.

Focus Indicators Navigation

Never use outline: none; in CSS unless you are replacing it with a custom, highly visible :focus state. Keyboard users need to see where they are.

3. Modern CSS Layouts

Flexbox (One-Dimensional)

Best for rows OR columns (e.g., Navbars, centering an item).

                .navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Grid (Two-Dimensional)

Best for full-page layouts and complex galleries.

.dashboard {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr;
  gap: 20px;
}
